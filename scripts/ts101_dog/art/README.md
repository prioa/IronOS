# Dog bitmaps

1 bit masters for the firmware, converted from photos that stay outside the repository.

- `kopf_b.png` (34x32): `photo_convert.convert((50, 38, 250, 240), (34, 32), 0.42, 0.5)`, then eyes and tongue touched up by hand.
  Home screen and soldering at temperature. `make_sprites.py` derives the poses.
- `portrait_gucci.png` (32x51): boot animation, upright on the panel; thresholded, then the cap, sunglasses, cigarette
  and bag were redrawn by hand. Used by `logo128.py`.
